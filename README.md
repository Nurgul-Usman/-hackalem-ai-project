# AI Study Assistant

## Project description

AI Study Assistant is a simple educational project designed to help students with their studies.

The project provides a friendly assistant that receives a student's question and gives a short motivational response.

## Goals

- Help students with learning
- Make studying more interactive
- Encourage students to keep learning
- Demonstrate a simple AI-based assistant concept

## Technologies

- Python
- GitHub

## How to run

Run the following command:

python main.py
